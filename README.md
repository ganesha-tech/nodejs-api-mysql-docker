# Node.js API with MySQL and Docker

A production-style REST API built with Node.js, Express, MySQL, and Docker.

## Tech Stack

- Node.js
- Express.js
- MySQL
- Docker
- Docker Compose

## Project Goals

- Build a REST API using Node.js and Express
- Connect the API to MySQL
- Containerize the application with Docker
- Use Docker Compose to run the API and database
- Manage configuration using environment variables
- Implement basic API health checks
